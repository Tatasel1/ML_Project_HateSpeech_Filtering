Reddit Virality Predictor

A Machine Learning project that predicts post success.

About the Project

This tool uses Artificial Intelligence to analyze if a Reddit post has a high chance of reaching "Trending".

How does it work?
  • Scraping: We collected thousands of posts from Reddit (Hot & New).
  • Processing: We analyzed title length, posting time, and text sentiment.
  • Modeling: A Logistic Regression model classifies the post as "Viral" or "Normal".
Model Accuracy: ~66% (Optimized for Recall)
